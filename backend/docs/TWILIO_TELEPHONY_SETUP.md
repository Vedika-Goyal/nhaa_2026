# 📞 Twilio Inbound Telephony Integration & Setup Guide (Subtask 13)

> **Module:** `app.routes.telephony` (`backend/app/routes/telephony.py`)  
> **Webhook Endpoint:** `POST /api/v1/telephony/voice` or `POST /api/v1/telephony/inbound`

---

## 🔑 1. Required Environment Variables

All configuration settings are loaded dynamically from environment variables. **No credentials or phone numbers are hardcoded.**

| Environment Variable | Required | Description | Example Value |
|---|---|---|---|
| `TWILIO_ACCOUNT_SID` | Yes | Your Twilio Account SID | `ACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx` |
| `TWILIO_AUTH_TOKEN` | Optional | Twilio Auth Token (used for HMAC signature validation) | `your_auth_token_here` |
| `TWILIO_PHONE_NUMBER` | Yes | Your assigned Twilio Phone Number | `+18885550199` |

---

## 🌐 2. Webhook URL Requirements

When an inbound phone call arrives at your Twilio phone number, Twilio makes an HTTP `POST` request containing form-encoded parameters (`CallSid`, `From`, `To`, etc.) to your server.

- **Primary Webhook Path:** `POST https://<your-domain>/api/v1/telephony/voice`
- **HTTP Method:** `POST`
- **Content-Type Expected:** `application/x-www-form-urlencoded`
- **Response Format Returned:** `application/xml` (Valid TwiML XML)

---

## 💻 3. Local Development Requirements (Using ngrok)

Twilio requires a publicly accessible HTTPS URL to reach your local FastAPI server during testing.

### Step-by-Step Local Setup:

1. **Start FastAPI Local Server:**
   ```bash
   uvicorn app.main:app --host 0.0.0.0 --port 8000
   ```

2. **Expose Local Server via ngrok:**
   ```bash
   ngrok http 8000
   ```
   *Copy the HTTPS forwarding URL generated by ngrok e.g. `https://a1b2-34-56-78-90.ngrok-free.app`.*

3. **Configure Webhook in Twilio Console:**
   - Log into [Twilio Console](https://console.twilio.com/).
   - Navigate to **Phone Numbers** -> **Active Numbers** -> Click your number.
   - Under **Voice & Fax** -> **A CALL COMES IN**:
     - Select: **Webhook**
     - URL: `https://<ngrok-id>.ngrok-free.app/api/v1/telephony/voice`
     - Method: `HTTP POST`
   - Click **Save**.

---
